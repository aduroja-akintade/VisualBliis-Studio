A zero-backend, editable motion graphic using SVG.js. Change the title and accent, replay the animation, then export a shareable portrait image.

Used for highlights and motion cues

Prototype only: it does not modify the main VisualBliis image editor. The CDN is version-pinned for experimentation. For production, install @svgdotjs/svg.js through npm and bundle locally.
